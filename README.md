Wustite is an open source UCI chess engine written in Rust with zero external dependencies. Its built-in NNUE network is trained with [Bullet][bullet], using self-play data generated by the tools in this repository.

Library API documentation is published on [docs.rs](https://docs.rs/wustite).

[bullet]: https://github.com/jw1912/bullet

## Getting started

### Precompiled binaries

Prebuilt binaries for Windows, macOS, and Linux are available on the [GitHub Releases page](https://github.com/scriptednob/wustite/releases), or via the installers below.

Linux and macOS:

```sh
curl --proto '=https' --tlsv1.2 -LsSf [https://github.com/scriptednob/wustite/releases/latest/download/wustite-installer.sh](https://github.com/scriptednob/wustite/releases/latest/download/wustite-installer.sh) | sh
```

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -c "irm [https://github.com/scriptednob/wustite/releases/latest/download/wustite-installer.ps1](https://github.com/scriptednob/wustite/releases/latest/download/wustite-installer.ps1) | iex"
```

Or install with Cargo:

```sh
cargo install wustite
```

> [!NOTE]
> Precompiled binaries are portable generic builds. They detect AVX2 at runtime on x86-64, but compiling from source for your own CPU enables BMI2 `pext` and AVX-512BW for noticeably higher speed.

### Building from source

Make sure you have `Rust 1.85` or newer installed ([official Rust installation guide](https://www.rust-lang.org/tools/install)). The AVX-512BW path requires `Rust 1.89+`.

Portable release build:

```sh
cargo build --release
```

Native build for your CPU:

```sh
RUSTFLAGS="-C target-cpu=native" cargo build --release
```

On AMD Zen 1 and Zen 2, hardware `pext` is microcoded and slower than magic bitboards—disable BMI2 on those CPUs:

```sh
RUSTFLAGS="-C target-cpu=native -C target-feature=-bmi2" cargo build --release
```

Non-x86-64 targets (including ARM) use magic bitboards and portable scalar NNUE code.

### Usage

Wustite is a UCI engine without a built-in GUI. Load it into a UCI-compatible front end such as [Cute Chess](https://github.com/cutechess/cutechess), [En Croissant](https://encroissant.org), [Arena](http://www.playwitharena.de/), or [lichess-bot](https://github.com/lichess-bot-devs/lichess-bot), or run it directly in a terminal:

```text
wustite
uci
position startpos moves e2e4 e7e5
go movetime 1000
```

### UCI options

| Name          | Default      | Description                                                                   |
| ------------- | ------------ | ----------------------------------------------------------------------------- |
| Hash          | 16           | Size of the transposition table in MiB [1–65536]                              |
| Threads       | 1            | Number of Lazy SMP search threads [1–256]                                     |
| Move Overhead | 30           | Time in milliseconds reserved per move for GUI/pipe lag [0–5000]              |
| Ponder        | false        | Allow the GUI to send `go ponder` [false–true]                                |
| UseNNUE       | true         | Use NNUE evaluation; when `false`, falls back to classical PeSTO [false–true] |
| EvalFile      | `<internal>` | Path to a `.nnue` network file, or `<internal>` for the embedded net          |
| Clear Hash    | —            | Clear the transposition table                                                 |

Internal search switches and margins can also be adjusted through `setoption` with integer values (`0` = off, non-zero = on), e.g. `setoption name NMP value 0`. See [`Params`](https://docs.rs/wustite/latest/wustite/search/struct.Params.html) and [`uci`](https://docs.rs/wustite/latest/wustite/uci/index.html) for the full list.

### Custom commands

Standalone CLI commands:

| Command                        | Description                                                   |
| ------------------------------ | ------------------------------------------------------------- |
| `wustite bench [depth]`        | Run the fixed-depth [benchmark][bench] (default depth 12)     |
| `wustite perft <depth> [fen]`  | Run a [perft][perft] leaf-node count from `startpos` or a FEN |
| `wustite divide <depth> [fen]` | Same as `perft`, broken down per root move                    |
| `wustite suite [max-depth]`    | Verify the built-in perft positions (default max depth 5)     |

Extra commands supported inside a UCI session:

| Command            | Description                                          |
| ------------------ | ---------------------------------------------------- |
| `d`                | Print the current board, FEN, and Zobrist hash       |
| `eval`             | Print the static evaluation of the current position  |
| `bench [depth]`    | Run the search benchmark inside UCI (default depth 10) |
| `go perft <depth>` | Print per-move perft counts for the current position |

[perft]: https://www.chessprogramming.org/Perft
[bench]: src/bench.rs

## Architecture

- **Board & move generation:** 64-byte aligned copy-make `Position` with incremental Zobrist hashing, fully legal move generation into a stack-allocated `MoveList`, and compile-time magic bitboards (or BMI2 `pext`).
- **Search:** Fail-soft PVS with iterative deepening, aspiration windows, quiescence search, and Lazy SMP. Uses check and singular extensions, null-move pruning (with verification at high depth), reverse futility, futility, LMP, LMR, SEE pruning, and IIR.
- **Move ordering:** TT move, SEE-split captures (MVV-LVA), two killers, counter move, butterfly history with gravity, and 1-/2-ply continuation history.
- **Evaluation:** Incrementally updated `(768 -> 128) x 2 -> 1` SCReLU NNUE with AVX-512BW, AVX2, and scalar paths. Classical PeSTO serves as a fallback, and bare-king endings against a rook or queen use a mop-up term.
- **Transposition table:** Lockless XOR-verified table shared across threads in 4-slot, 64-byte cache-line buckets.

## Training and tools

Self-play data generation lives in `examples/datagen.rs` (written in pure Rust, outputting `fen;score;wdl` lines):

```sh
cargo run --release --example datagen -- --out data.txt --threads 4 --positions 2000000 --nodes 8000
```

Pass `--net FILE` to label positions with an existing network instead of PeSTO. The built-in network is trained from this data using [Bullet][bullet]; the repo also includes a standalone pure-Rust trainer (`examples/train.rs`) and a magic multiplier finder (`examples/find_magics.rs`).

Match testing and opening book generation live in `tools/` and require Python 3 with [python-chess](https://github.com/niklasf/python-chess):

```sh
python3 tools/make_openings.py target/release/wustite tools/openings.txt 200
python3 tools/match.py --bin target/release/wustite --openings tools/openings.txt --movetime 60 \
    --a "evalfile=net.nnue" --b "evalfile=nets/wustite.nnue" --games 400
```

Run tests and local API docs with:

```sh
cargo test --release
cargo doc --no-deps --open
```
